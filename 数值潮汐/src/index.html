玩法说明

战斗怎么算

走进敌人格就会开战，整场对决一次算完。

伤害 = 攻击 × 50 / (有效防御 + 50)
有效防御 = max(0, 防御 − 对方穿透)

防御的收益是递减的：50 点减半，100 点减 2/3，200 点减 80%。 所以堆防御能扛，但堆不出无敌。

物理和法术各算一遍，系统自动挑伤害高的那一路。 你要判断的不是"怎么打"，而是"打谁、绕开谁、把属性堆到哪条线上"。

敌人是偏科的

石甲兽物防 26、法防 0；幽魂法防 28、物防 0。 用错伤害类型会打得非常慢，而每一轮你都在挨打。

鼠标移到敌人身上会直接告诉你建议用哪一路、几轮能杀掉、 这一场大概要掉多少血。

移动

按方向键 / WASD：走一格（最基础的方式）。

按住不放：连续走，松手即停。

点击远处：自动寻路走过去，青色小点就是路线。长按鼠标则边走边跟踪目标。

空格：原地等一回合。

魂技

每个职业有一个主动技能 + 冷却。按 Q，或点右上角的技能键释放。

技能和普攻是两种东西：普攻负责"一直有输出"，技能负责 在正确的时机换一个局面 —— 被贴身时反打、隔着半个房间先手、 换一次额外行动、残血时硬顶三回合。

冷却会写在技能键上，侧栏也有一条冷却进度。 范围里没有目标时释放失败不会消耗冷却，不必怕点空。

四个技能各有招牌机制：裂地斩把身边的敌人掀开一格，掀不动的会被 震晕一回合；潮语洪流让敌人潮湿两回合，之后用法术打它更疼； 疾影给两次免费行动，且期间你的攻击 +35%； 不退之壁三回合双防 ×2.5，还会反弹一半受到的伤害。

「震晕」「潮湿」会画在敌人身上（头顶转圈的星 / 一层水光）， 把鼠标移上去还能看到各剩几回合。

潮汐

水位按 0 → 1 → 2 → 3 → 3 → 2 → 1 → 0 循环。 涨潮时水面从水洼扩散开，通路变窄，而且站在水里每回合掉血； 退潮时水面退回原位，是绕路、开宝箱、找泉水的窗口。

所以压力不是"血条在漏"，而是"窗口在关闭"。

背包 / 装备 / 出售

按 E 打开整屏背包。把装备拖到左侧槽位穿戴， 拖到出售区换成金币，拖到其它格子只是整理顺序。

悬停任何一件会显示和身上那件的逐项差值，不用自己心算。 「一键出售劣质品」会卖掉所有不如当前装备的。

把一件拖到另一件同品质的装备上就是融合：两件合成一件高一档的， 费用按产物的身价算。松手之前气泡里会先写清结果和花费 —— 融合会消耗掉两件材料，别手滑。

商店与金币

每层地图上有 2 处潮汐商栈（金色摊位，小地图上也是金色）。 走到上面会自动打开商店。

金币来自击杀、宝箱和出售装备。商栈里可以买装备、买潮汐圣水回血， 也可以花金币刷新货架。每下一层货架会整体换新。

潮汐结晶 0

每一局结束按「深度 ×12 + 击杀 ×2 + 通关加成」结算成结晶。 兑换的是永久增益，下一局开场就生效；只影响你自己的存档，不动平衡数据。

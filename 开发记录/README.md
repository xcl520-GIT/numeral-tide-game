## 怎么读这些数字

- **主尺子是 n=900**（`?n=900&diff=all&cls=0`）。`n=300` 只够看方向 ——
  往敌人表里加一条就会重排随机流，改动前后不是同一批世界。
- 每个阶段的三档通关率要**连第 1 层死亡数一起看**：前者是结果，后者是"难度温度计"。
- 遇到"看起来没变化"的结论，先问一句：是不是**这条链上的对手**根本不存在
  （v11.10 的穿透就是这个问题：怪物的穿透一直是 0，所以防御没有对手）。

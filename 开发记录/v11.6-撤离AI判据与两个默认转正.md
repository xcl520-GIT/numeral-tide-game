## 一、撤离的 AI 判据重定（三步，一步比一步深）

### 第 1 步：判据的**语义**错了（不是数写小了）

老判据是工作单原文的"预期本轮承伤 > 剩余血 30%"。实测 **22 次/局 ≈ 逢战必撤**，
通关率 −19.6 / −15.0 / −13.7pp。两个错处：

1. 它算的是"这一轮疼不疼"，不是"这一场会不会输" —— 上一轮的疼下一轮照样能打，
   撤了却把整场的收益（击杀 / 掉落 / 升级）全丢掉；
2. 群战里它把所有活着的敌人的攻击**加起来** —— 4 只 × 15 点轻松越过剩余血的 30%，
   于是"被围观 = 必撤"，而那恰恰是群战机制存在的场合。

改成**应急出口**：预期本轮承伤 ≥ 剩余生命就撤（`FLEE.aiFleeAt = 1.0`）。
结果：−3.3 / −1.6 / −3.7pp，撤离 25 / 8.8 / 1.5 次/局 —— **casual 反而更高**。

### 第 2 步：**撤离循环**（撤完不跑）

casual 次数最高说明它不是"偶尔的应急出口"，而是**同一个局面被反复撤**：
AI 贴着敌人 → 判"下一击会死" → 撤 → 下一回合又是同一个局面。
补上**脱离期**（3 回合，往远离敌人的方向走一格）：撤离降到 4.7 / 1.1 / 1.1 次/局，
−0.6 / 0.0 / −2.3pp（1σ 以内）。

### 第 3 步：终检逮到**免伤循环** → 加冷却

新默认档的深渊出现 **1 例 timeout**（此前连续多轮都是 0：trace 是 `12,32 ↔ 11,32`
两格震荡，玩家 3 点血、身边 1 只怪、在场 24 只、kills 83）。
两个根因：

| 根因 | 性质 | 改法 |
| :--- | :--- | :--- |
| `_retreatStep` 只看"最近那只"敌人，身边一多它就换人 → 方向来回翻 | 我引入的**两格横跳**（正是 `_autoStep` 用"目标承诺"防过的那类） | 改成**势能严格下降**：对附近每只敌人算分数，只走更好的那格 —— 严格递增 ⇒ 结构上不可能回来 |
| **撤离没有冷却**：每回合都能撤，而脱接触每次让那只怪"这一回合不追" ⇒ 每回合都不挨打 | **规则上的洞**（玩家也能这么用） | 加 3 回合冷却（`FLEE.cd`），界面同步显示剩余回合 |

### 定稿：**AI 不该主动撤**（数据说的）

| 配置 | 休闲 | 标准 | 深渊 |
| :--- | ---: | ---: | ---: |
| cd=1, **fleeai=0**（默认） | **72.7** | **42.3** | **29.3** |
| cd=1, fleeai=1 | 67.0 | 39.0 | 26.3 |
| 差 | −5.7 | −3.3 | −3.0 |

判据重定、撤完脱离、冷却三件做完之后，AI 主动撤仍然是**净亏**，casual 超出 1σ。
之前量到的"接近中性"（−2.0/−0.6/−1.0）是**靠没有冷却换来的**，而那正是免伤循环的来源。
根因还是那条：这里撤离换不到**可靠**的安全（战斗从相邻开始，推开一格 + 一回合不追，
而场上有二十几只，下一回合换一只照样贴上来），代价却是确定的。

**所以机制全留、默认不启用**（`fleeai=0` = 死战到底）。打开 `?fleeai=1` 可复现上表。

## 二、冷却口径转正（一次有意的难度下调）

`?duelcd` 从默认 0 改成 **1**（冷却随战斗轮走）。**比立项时估的更大**：

| | 休闲 | 标准 | 深渊 |
| :--- | ---: | ---: | ---: |
| 转正前（cd=0） | 64.3 | 33.3 | 27.0 |
| **转正后（cd=1）** | **72.7** | **42.3** | **29.3** |
| 差 | +8.4 | +9.0 | +2.3 |

原估算（+1.6/+6.6/+4.3）是**在 duelskill=0 时量的**。带着魂技再量，差得多：
冷却走快之后 **AI 用魂技的次数翻了四倍**（542 → 2091 次/档）——
而 skillCd 是全游戏唯一**随回合变好**的资源，所以"冷却走得更快"这件事
几乎全部被魂技吃掉了。这一条是本轮最值得记的**交互**。

## 三、P5 重验：**立项依据已经过期**

用 `_probe/v11.6/probe_p5.html` 重测三件事（深渊 n=60）：

| 指标 | v11.4-f 的说法（立项依据） | 现在实测 |
| :--- | :--- | :--- |
| 玩家每击伤害 | "实测每击 203 点" | 中位 **102** ｜ p90 **294** ｜ 最大 1443 ｜ ≥200 的占 23.5% |
| 第 5 层杂兵血线 | "200~240 血" | 中位 **407** ｜ 平均 432.6 ｜ 最大 597 |
| 深渊一轮结束 | 43% | 43%（n=500） |

**结论**：立项时那句"一击 203 点 vs 杂兵 200~240 血"**已经过期** ——
怪的血线翻了一倍（A1 把普通怪血量抬上去的直接后果），
而玩家每击的中位只有 102。**"一击秒一只"不成立，雪球没有滚起来。**

于是 P5 按原方案做是**做错药**：`?equipdecay`（装备加成递减）治的是
"后期面板碾压"，而现在的中位伤害连一只杂兵都要两下。
要动的话，症状描述得重写（现在更像"每击伤害的分布拉开了"：中位 102 vs p99 633）。

⚠ 一句提醒：这一轮 `duelcd` 转正让 abyss 通关率 +2.3pp，
P5 的立项描述本来就依赖"深渊第 1 层死亡 189 → 现在 188"，这套数字得跟着更新。

### 一句话结论

**P5 的病是真的，但病根不在装备上。**

- 真根因：`speedGap = 18` 的「速度碾压每轮多打一次」。速度差 ≥18 时一轮结束率 **76%**，
  <18 只有 **19.8%**（差 **56.2pp**，且在 18 处有一道明显台阶）。
- **v11.6 说"雪球没有滚起来"是错的**：局内配对实测同一局第 5 层每击伤害是第 1-2 层的
  **4.57 倍**（63 局无一低于 2 倍），遗物从 0 件涨到 16 件。它只是被敌人血线的层数缩放
  （×3.5）对冲掉了，所以没变成"一击一只"。
- 工作单推荐的药方（装备加成递减）**量化证伪**：遗物 mods ±30% 只值 ±2.5pp。

## 五、环境坑（新话题最容易在这里浪费时间）

1. **给热对象加字段 = 整局慢 3 倍。** 字段必须在 `reset()` / `_makeEnemy()` 的字面量里声明。
   探针要存每局状态时用 **`Map`/`WeakMap`**（本轮的配对探针就是这么做的），别挂到 Game 上。
2. **无头 `--dump-dom` 下 `requestAnimationFrame` 不跑**。任何"动画跑过之后"的断言都不能这么测。
3. **同一个文件，`Get-Content` / `Select-String` / `readFile` 报的行号互不相同**
   （本轮实测 `smoke.html`：Get-Content 4449 行，Select-String 说第 54 节在 4592 行）
   → 一律用**文本锚点**定位，不要按行号改文件。
4. **PowerShell 不支持 heredoc**（`git commit -F -` 会直接解析失败）
   → 提交信息**写成文件**再 `-F`；Python 也一律**写成 `.py` 文件再跑**。
5. `--virtual-time-budget` 会让 `--dump-dom` / `--screenshot` **挂死**；截图不能加它。
6. 残留 msedge 占 profile → 输出 0 字节假象。**只杀带 `--headless` 且本项目 profile 的实例**。
   ⚠ 两个 `run_page.ps1` **不能并行**（后启动的会杀掉先启动的那个实例）—— 必须串行。
7. 控制台是 GBK → 含中文的输出要**写文件再读**。
   `run_page.ps1` 的 `-out` 参数指定输出文件，再用 `readFile` 读它，是本项目最稳的取数方式。
8. `editFile` 的 `old_string` 含 `$` 或空白差异会**静默失配**；多处改动用 Python 字节替换 + 命中数断言。
9. `grepContent` 在本项目的中文路径下返回 `0 locations`（不可用）→ 用 `Select-String`。
10. **`run_page.ps1` 的 `-url` 是完整 URL**：本项目是
    `$b = ".../数值潮汐/tools"`，探针是 `$b/_probe/<阶段>/xxx.html`。
    写成 `$b/smoke.html` 会 404（`smoke.html` 在 `tools/` 下），而 404 页面照样有 300KB 输出、
    照样报 `bytes=...`，**看起来像跑完了** —— 必须检查内容里有没有 `file:///` 错误页。
11. 临时脚本放 `数值潮汐\_probe\<阶段>\`，不要倒在工作区根目录。

# v11.7 · P5 重写立项与落地 —— 真根因是「速度碾压」，不是装备雪球

> 2026-09-24。**8 发探针 + 1 处机制改动 + 1 条新断言**。
> 触发原因：v11.6 把 P5 判为"立项依据过期、要重写"，但**那一次只量了三个数就下了结论**。
> 这一轮把它量到底，结论**推翻了 v11.6 自己**，并找到了真正的病根。
> 探针在 `数值潮汐\_probe\v11.7\`，原始输出 `out_*.html`。

## 一、一句话结论

**P5 的病是真的（深渊「一轮结束」39.5% > 验收线 35%），但病根不在装备上。**

| | v11.6 的说法 | v11.7 实测 |
| :--- | :--- | :--- |
| 雪球 | "没有滚起来，P5 可能要挂起" | **滚得很猛**：局内第 5 层每击伤害是第 1-2 层的 **4.57 倍**（63 局无一低于 2 倍） |
| 病根 | "装备主导" | **速度碾压**：速度差 ≥18 时一轮结束率 **76%**，<18 只有 **19.8%** |
| 药方 | 装备加成递减（工作单 a） | **证伪**：遗物 mods ±30% 只值 ±2.5pp，第 1 层死亡一个都不动 |

雪球确实存在，只是被敌人血线的层数缩放（×3.5）对冲掉了，所以没变成"一击一只"。
**而"一轮结束"不达标是另一件事，它由 `speedGap` 决定。**

### 为什么第 2 发是必需的（方法论）

第 1 发的判据是**跨局聚合**：只有活到第 5 层的局才贡献"5 层"那一行，
而那些局的玩家本来就强 —— 于是任何成长都会被读成雪球（**幸存者偏差**）。
第 2 发做**局内配对**（同一个 game 实例横向比），才把"雪球"和"开局运气"分开。
**63 局里没有一局低于 2 倍**，这条结论因此站得住。

> 这正是 v11.6 犯的错：它用跨局聚合的三个数（中位 102 / p90 294 / 血线 407）
> 就判"雪球没滚起来"。**三个数里没有任何一个能回答"同一局内越打越痛吗"。**

## 三、三个被数据否掉的假设

### ① 「装备雪球导致面板碾压」—— 依据过期，且药方无效

| 假设的说法（v11.4-f） | 实测（v11.7） |
| :--- | :--- |
| 深渊每击 203 点 | 中位 **68** ｜ p90 218 ｜ p99 509（n=300 逐击） |
| 第 5 层杂兵 200~240 血 | 中位 **407** ｜ 平均 432.6 |
| "一击秒一只" | 击杀一只普通怪的**中位出手数 = 2** |

更要紧的是第三发：**把装备加成整体砍 30%，验收指标几乎不动**。

### ② 「提高后层杂兵血线」（工作单方案 b）

病在"**出手次数**"，不在"每次打多痛"。抬血线只会把"2 手打死"变成"3 手打死"，
轮数被拉长 —— 这正是工作单自己担心的"反噬 A1 达标线"（第六发实测 2.04 → 2.22）。

### ③ v11.6 的「雪球没有滚起来，P5 可能该挂起」

见第一节。局内 **4.57x**、遗物 0→16 件。雪球滚得很猛。

## 四、真根因：那一道台阶

**core.js `step()` 里两个"每轮多打一次"的来源，第一个不需要任何遗物：**

```js
// 速度碾压：快的一方多打一次
const gap = num(src.st.spd) - num(dst.st.spd);
if (gap >= SG && src.hp > 0 && dst.hp > 0) strike(src, dst, t, fx);
// 连击词条：达标就每轮两次
if (num(src.flags.doubleAtSpd) > 0 && ...) strike(src, dst, t, fx);
```

全局 `C.speedGap = 18`。而职业基础速度是 **游侠 26** / 战士 11 / 法师 10 / 守护者 8，
杂兵速度多在 **4~16** —— **游侠开局就对多数杂兵踩在这条线上**。

第五发按速度差分桶（深渊，1v1 + normal + tier≤1 + 野生，n=2223 场）：

| 速度差 | 场次 | 一轮结束率 |
| :--- | ---: | ---: |
| <0 | 407 | 15.7% |
| 0-8 | 629 | 17.5% |
| 9-17 | 408 | 27.5% |
| **18-25（触发）** | 370 | **66.5%** |
| **26+（触发）** | 409 | **84.6%** |

**单调上升 + 18 处有台阶 + 两组差 56.2pp**（≥18 → 76%，<18 → 19.8%）——
三条预写判据全部命中。一轮结束的场次里 **67.4%** 速度差 ≥18；多轮场次里只有 13.9%。

> **为什么"中位要 2 手"却"40.8% 只打一轮"**：**「一轮」不等于「一次出手」**。
> 速度碾压让一轮里玩家出手 2 次，而杂兵血线正好是"2 手"的量级 ——
> 于是"一轮 = 2 手 = 击杀一只"，在数字上就成了"一轮结束"。

## 五、药方：三个候选，两个被否

| 方案 | 深渊一轮结束 | 深渊通关 | 第1层死亡 | 休闲/标准 | 判定 |
| :--- | ---: | ---: | ---: | :--- | :--- |
| **a 装备加成递减**（工作单推荐） | 38.2%（×0.7 mods） | 30% | 122 | 几乎不动 | ❌ 无用 |
| **A 全局 `speedGap` 18→26** | 32.8% ✅ | 29.5% | 131 | **标准 −9.0pp** | ⚠ 代价太大 |
| **C 只给深渊的怪加速度** | 33.4%（×1.5） | 22.7%（−6.6pp） | 214 | 不动 | ❌ 把碾压换给了怪 |
| **E 只给深渊更高阈值** | 32.8% ✅ | 29.5% | 131 | **逐位相同** ✅ | ✅ **采用** |

**C 为什么被否**（第七发）：预写判据是"达标 + 怪碾压玩家占比 <5% + 通关率掉 <5pp"。
×1.5 时三条全不过：怪碾压玩家 **10.8%**、通关率 **−6.6pp**、第 1 层死亡 214。
它就是"把碾压从玩家身上换到怪身上"，而不是治好了。

**E 为什么成立**：`speedGap` 是**全局常数**，而"一轮结束"不达标的**只有深渊**
（休闲 27% / 标准 29.8% / 深渊 39.5%，线是 35%）。
把阈值**按难度给**，疗效就精确落在深渊里（第八发：三种阈值下休闲/标准**全部逐位相同**）。
gap=26 与 gap=30 结果几乎相同（32.8% vs 32.5%）—— 收益在 26 处饱和，所以取 **26**。

## 六、落地实现（三处改动 + 一条断言）

| 文件 | 改动 |
| :--- | :--- |
| `src/js/core.js` | `newDuel` 里加 `const SG = num(this.diff && this.diff.speedGap) \|\| C.speedGap;`，`step` 里把 `C.speedGap` 换成 `SG` |
| `src/js/data.js` | `abyss` 加 `speedGap: 26`（附原理注释） |
| `tools/smoke.html` | 新增**第 55 节**：速度差 20 时**标准 2 次 / 深渊 1 次** |

**这个写法的关键**：`speedGap` 是**可选字段** —— 不写就用全局默认，
于是"没有覆盖"与旧行为**逐位相同**。**删掉 data.js 那一行即回退**，
这就是它唯一的对照口径，也是逐位比对能成立的前提。

### 冒烟断言必须同时盯两头

```
ok  P5：速度碾压阈值按难度走 —— 速度差 20 时标准 2 次 / 深渊 1 次
    （深渊阈值 26 生效，其余档走全局 18）
```

只盯深渊那一头是不够的：**"标准仍然是 2 次"才是"影响面锁在深渊"的唯一证据**。
（三档逐位比对是它的粗粒度版本，这条是细粒度版本。）

## 八、四条教训

1. **跨局聚合的成长曲线不能用来判"雪球"。** 它有幸存者偏差，
   会把"活得久的玩家本来就强"读成"越打越强"。要么做局内配对，要么别下结论。
   —— v11.6 就是拿三个跨局聚合的数下了结论。
2. **验收标准要回到工作单原文去读。** P5 的验收是"一轮结束 43% → ≤35%"和
   "第 1 层死亡 <120"，不是"一击 203 点"。**立项依据是解释，验收标准才是靶心**，
   两者混起来会导致"打中了解释、没打中靶"。
3. **加了一个新变量，要记得把使用处也换掉。** 本轮 `SG` 定义加了、
   使用处忘了换，是**第 55 节断言当场抓到的**（它报了"深渊实测 2 次"）。
   如果没有那条断言，这个洞会表现为"改了跟没改一样"，而且极难发现 ——
   因为游戏照样能玩、三档数字也只差几个 pp。
4. **灵敏度分析不必先实现。** 第三/六/七/八发全是在探针里**改内存里的常数**
   （跑完立刻还原），就量出了"药方走多远、代价多大"。
   源码一个字节没动，却把三个候选方案淘汰了两个。

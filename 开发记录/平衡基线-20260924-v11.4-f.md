## 二、A1 的达标线

判据（工作单定的）：**单怪场均轮数 ≥2.0、一轮结束占比 ≤30%。**

「单怪」按两个口径分别报，因为两者确实是两件事：

| 难度 | 口径 | 改动前 均轮 / 一轮结束 | **改动后 均轮 / 一轮结束** | 达标 |
|---|---|---|---|---|
| 休闲 | 野生普通怪 | 1.49 / 67% | **2.44 / 28%** | ✅✅ |
| 标准 | 野生普通怪 | 1.46 / 68% | **2.44 / 29%** | ✅✅ |
| 深渊 | 野生普通怪 | 1.26 / 81% | **2.01 / 43%** | ✅ / ❌ |
| 休闲 | 含孢子母的幼体 | 1.31 / 79% | 2.15 / 39% | ❌ / ❌ |
| 标准 | 含孢子母的幼体 | 1.26 / 81% | 2.06 / 43% | ✅ / ❌ |
| 深渊 | 含孢子母的幼体 | 1.14 / 90% | 1.66 / 59% | ❌ / ❌ |

**为什么"含幼体"要单列**：`幼体` 是孢子母每 3 回合产一只的召唤物，
按设计它就该比野生怪弱一档（代码里用 `depth-1` 的黏液怪模板造）。
深渊的 1v1 杂兵里 **53% 是幼体** —— 拿它去跟"野生普通怪"平均，
量到的其实是"打召唤物要几轮"，那是另一件事。
两个口径都记下来，是为了让读者自己判断，而不是挑一个好看的。

**残留（没做到的）**：`一轮结束 ≤30%` 这一条，只有休闲/标准（28% / 29%）达成；
深渊 43%。原因不是这次的曲线没调够，而是**深渊的玩家面板本身过高**：
深渊一局 55.7 杀 → 8.7 件秘藏 → 实测每击 203 点，而深渊第 5 层的普通怪才 200~240 血。
这是工作单「发现 2」里那条**装备主导的雪球**（"高杀数时装备是主导…那需要单独一轮"），
不在本轮范围内。本轮能做的都做了：把"一刀秒"从 67~81% 压到 28~43%。

## 三、最终数值（`src/js/data.js`）

### 3.1 普通怪（tier 1）—— **只动这一档**

| 怪 | 血 | 攻击 | 改前的血 / 攻 |
|---|---|---|---|
| 黏液怪 | 38 → **115** | 10/7 → **6/4** | |
| 石甲兽 | 66 → **100** | 16 → **9** | |
| 幽魂 | 42 → **85** | 20 → **11** | |
| 疾风兽 | 34 → **102** | 14 → **8** | |

**血量倍数刻意不统一**（3.0 / 1.5 / 2.0 / 3.0）：判据是"它本来就多难啃"。
石甲兽（defP 26）与幽魂（defM 28）本来就吃得住 1.5~2 刀，而且**防御还会随深度放大**，
再乘 3 会把它们变成深渊第 5 层 10 轮以上的肉墙 —— 那不是杂兵该有的样子。
实测印证：均匀乘倍率时尾部长到 21 轮，拆开之后最长落在 15 轮、
且 90 分位从 5.4 降到 3.9。

### 3.2 精英与首领 —— **一律不动**

工作单的取证建议就是"先只动普通怪，精英与首领暂时不动，这样基线的移动只来自一个变量"。
我试过给精英 +20% 血 / −15% 攻（n=200），收益在噪声里，按归因清楚的原则回退了。

### 3.3 `STANCE.every`：3 → 2

不是难度改动（硬化 ×1.5 / 软化 ×0.5 是零和重分配，平均强度恒为 1.0），
改的是**翻面频率**，也就是这条线索的可读性。旧值 3 是配旧战斗长度定的：
那时能打 3 轮以上的只有精英，`every=3` 恰好等于"精英战里翻一次"。
普通怪变成 2~3 轮之后，`every=3` 反而变成"整场都看不到翻面"。

## 四、这个数是**扫出来的**，不是拍出来的

（扫描器：`tools/probe_hpcurve.html`，一次扫描同时给出达标线与通关率。）

四条被数据否掉的路线，记在这里是为了不让它们被重新提一遍：

| 试过的做法 | 结果 | 为什么否掉 |
|---|---|---|
| 均匀抬普通怪血量（×1.6/×2.2/×3） | 均轮 1.4→2.1，但 standard 通关率 66%→10% | 只抬血量 = 敌人多出手几轮 = **难度翻倍**，不是"战斗变长" |
| 血量×攻击一起动（2:0.7 / 2.5:0.5） | standard 52~64%（噪声大），一轮仍 44% | 方向对，但幅度不够，且"含召唤物"口径被幼体拖住 |
| 抬 `enemyHpPerDepth`（0.34→0.9） | 深渊几乎不动（1.04→1.35），standard −17pp | 深渊的问题在第 1 层与第 5 层的**两端**，靠"每层成长率"够不着 |
| 只动 tier-1、精英首领不动 | **通关率几乎不动，均轮 1.46→2.44** | ✅ 采用 |

**关键量**：探针同时记"面板单击"和"实测每击"。**实测每击是面板的 1.5~3.5 倍**
（遗物 flags + 暴击 ×1.9 + 克制奖励的真实伤害 ×1.25，且倍数随深度上升）。
第一版手算全错在这里 —— 拿"面板单击"去配血量，永远配不到点上。
所以这个项目里"敌人该有多少血"只能**扫**，不能算。

## 五、这一轮顺带抓到的两个真问题

1. **魂技 AI 的触发条件是旧战斗长度的残留**。`裂地斩` 的 AI 判据是"这一下能收掉它"——
   杂兵一刀死时几乎总成立，血量上调后变成**永不成立**：实测破军一整局 **58% 的概率一次魂技都不放**。
   这不只是"AI 变保守"，而是魂技这个机制在模拟器里**完全消失**（模拟器通关率是本作唯一的验收标准）。
   已改成按它自己的设计触发（"被贴身就一定能反打" → 身边有人就放）。
   冒烟抓到，已加断言守着。
2. **我自己写的断言先错了一次，被自己抓到**：`newDuel` 的 `B` 参数是**属性对象本身**
   （hp/maxHp 直接挂在它上面），我多包了一层 `{st: B}` → `st.spd` 变成 undefined →
   速度差算成 26 → 白送一次速度追击 → 断言误报"疾风×幽魂 被一刀秒"。
   记在这里是因为**调用约定没有类型保护，只有约定**，下一个人还会踩。

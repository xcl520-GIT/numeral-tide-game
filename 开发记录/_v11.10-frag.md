## v11.10 · 指标常驻化 → 前两层搬家 → 给防御一个对手（2026-09-24）

三项一起做的，顺序即依赖顺序：**先把尺子钉牢，再用尺子把难度搬家，最后给防御补个对手。**
三项各自一个提交、各自跑过冒烟 + 300×3。三档 **72.7 / 42.3 / 22.3**，冒烟 291 ALL PASS，
体检 19/0，900 局 0 stall。

### ① 「后半程压力」进了常驻指标行

条件概率（到过第 3 层的局里有多少死在第 3-4 层）从此不用再写探针。
两个口径坑在实现里堵住：**通关局也写在 `byDepth` 里**（必须先按 depth 摘掉赢家，
否则标准档算出 `(8+132)/140 = 100%`）；**分母取 `endDepth>=3` 的全部**，
而不是"第 3 层死亡 + 赢家"（第 4 层有死亡时会漏算 —— v11.8 那组 `{3:4, 4:1}` 正好会少算 1）。
输出配着 `(死亡/到达)` 一起给。

**教训（新）**：`n=300` 时这个数的 1σ ≈ **±4.2pp**（分母只有 89 局）。
同一基准 `n=300` 读 20.2%、`n=900` 读 16.6%。**以后读它必须连着样本量一起读。**

### ② 深渊前两层门槛 —— 搬家，不是降难度

**先补一条结构认识**：第 1 层**不吃 `enemyScale`**，强度旋钮只有 数量 / 精英 / 补给 三个，
而前两个 v11.8 已证伪。⇒ **补给是第 1 层唯一还剩的杠杆** ——
这就是 v11.8 那张表为什么"每一条有效的药方都在降难度"。

转折点是 v11.9 的 `deepCorrupt`：它让"削前两层 + 补后半程"第一次可以**不是降难度**。
采纳 **M1**：`healAfterWin` .024→.040（= 标准档）+ `deepCorrupt` .06→.105。
n=900 实测：通关率 21.8% → 22.8%、**总死亡 704 → 695（守恒）**、
第 1 层死亡 627 → 541、**到达第 3 层 241 → 305（+27%）**、第 3-4 层死亡 40 → **94**。

**复活流被干净否掉**（`extraLife 1` + 腐蚀 .135）：通关率 35.3% 越档、
总死亡 194（**不守恒**）、单局回合翻倍 —— 它让本该结束的局继续跑，是"换游戏"不是"搬家"。

### ③ 装备堆防御那条债 —— 给防御一个对手

债的原文在 `data.js` 的 PROGRESSION 注释里（"卡死局面 defP 231~299 是装备堆出来的"）。
5 发探针拆成三层：

- **症状不在了**：三档 max defP = 111/139/**192**，够不到 231~299，900 局 0 stall；
- **防御是生存支柱**：消融掉 **8.0/8.3/7.0pp**。
  ⚠ 第一发读到"defP≥150 的 11 局全部通关"是**幸存者偏差**（通关局 683 回合，自然捡到更多装备）
  —— v11.6 栽过同一个，**分开两者的唯一办法是消融**；
- **怪物的穿透恒为 0**：`_scaleEnemyStats` 只缩放 hp/atk/def，`penP/penM` 原值透传，
  而 ENEMIES 模板没一个写 `penP`，被兜底补成 0。**防御在打一场没有对手的仗。**

**药方 = 穿透**（不是抬攻击）：`atk·K/(def+K)` 是饱和的，抬 atk 先杀低防玩家；
**穿透是减法**，削防御的绝对量 —— 它是唯一能"**对抗**防御"的手段
（`deepCorrupt` 是"绕过"）。
分桶实测它**打在谁身上**：低防桶（200 局，全死在前两层）承伤 6.1 → 5.9**纹丝不动**，
中防桶承伤 2.4 → 3.0、通关率 71.9% → 60.3%。**不是又一次整体加难度。**
落点 `penPerDepth: 8`（n=900）：−2.7pp、**第 1 层逐位不变**、
装备防御的价值 6.9pp → **4.2pp**（仍有用，但不再是万能）。

### 本轮踩到的两个新坑

- **断言别把参数写死**：`smoke.html` 第 56 节原来写死"6%"，`deepCorrupt` 一调到 0.105 就 FAIL，
  而它报的样子（"扣多了"）和"机制坏了"**一模一样**。改成从数据表读。
- **探针里覆盖函数别忘了它可能有兜底分支**：第三发给怪"乘穿透"，三组读数**逐位相同** ——
  因为基础 `penP` 是 0，乘 0 还是 0。这个 bug 反而撞出了正确答案，
  但**如果不是"全不动"这种极端读数，它会被漏掉**。
